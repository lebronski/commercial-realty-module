# map_app

Веб-сервис для работы с картой города (Йошкар-Ола по умолчанию).
Граф дорог + здания + характеристики, всё хранится локально в SQLite.

## Зависимости
- Flask
- folium (рендер карты Leaflet)
- osmnx (скачивание данных из OSM/Overpass для модуля интеграции)

## Быстрый старт

    python -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt
    python app.py

Открыть http://127.0.0.1:5000

## Разделы
- **Карта** — интерактивная карта Leaflet, редактирование графа и зданий.
- **Характеристики** — CRUD характеристик (для узлов / рёбер / зданий).
- **Типы построек** — CRUD типов с цветом.
- **Модули → Управление модулями** — установка/активация модулей (.py).
- **Модули → Модуль интеграции с Overpass API** — импорт дорог и зданий
  города из OSM, с настройками и фоновым прогрессом.

## Модули

Модуль — это .py-файл в каталоге `modules/`. Он должен содержать:

    MODULE_INFO = {
        'name': 'overpass',
        'description': 'Интеграция с Overpass API',
        'version': '1.0'
    }
    MENU = {'url': '/modules/overpass', 'title': 'Модуль Overpass'}

    def register(app, loader):
        # можно регистрировать роуты через app.route(...)
        ...

После установки модуля нужно перезапустить приложение, чтобы его роуты
зарегистрировались. Отметка «активен» хранится в таблице modules БД.

## Оффлайн

Тайлы карты по умолчанию берутся с публичного сервера OpenStreetMap — при
полном отсутствии интернета подложка не подгрузится, но граф и здания
работать будут. Для полностью оффлайн-карты поднимите локальный
тайл-сервер и укажите его URL в `app.py` в `folium.Map(..., tiles=...)`.
