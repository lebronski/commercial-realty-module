# Модуль «Коммерческая недвижимость» — установка

Тепловая карта коммерческих помещений и зданий региона (по умолчанию Марий Эл),
индекс ликвидности, модельная цена покупки и доход от аренды. Данные — OpenStreetMap
через Overpass API. **Цены — оценка по модели, а не данные объявлений.**

## Что модулю нужно от проекта

Только объект Flask `app`. Модуль **не требует правок** в `app.py`, `db.py`,
шаблонах и стилях проекта и не создаёт таблиц в его базе:

| Что | Где у модуля |
|---|---|
| Данные и настройки | свой файл `commerce_realty/data/commerce.db` (создаётся сам) |
| Страница и API | свой Flask Blueprint, адрес `/modules/commerce/` |
| Шаблоны, CSS, JS | внутри пакета, раздаются самим Blueprint |
| Оформление | общий `base.html` проекта, если в нём есть блок `content`; иначе своё |
| Стили | только свои классы `cm-*`, `style.css` проекта не нужен и не затрагивается |
| Зависимости | `flask`, `requests` — те же, что у проекта |

Из проекта модуль только *читает*, если найдёт: шаблон `base.html` и настройку
`overpass_servers` модуля Overpass (чтобы взять тот же сервер). Если их нет —
работает со своими значениями.

## Состав

```
modules/
├── commerce_module.py        ← точка входа для загрузчика модулей
└── commerce_realty/          ← весь модуль
    ├── model.py              расчёты: факторы ликвидности, цены, доходность
    ├── osm.py                запросы к Overpass API
    ├── storage.py            своя база SQLite
    ├── web.py                страница, API, фоновая загрузка
    ├── templates/ static/    шаблоны, CSS, JS
    ├── install.py            установка в другую копию проекта
    ├── standalone.py         запуск без проекта
    └── loader_entry.py       эталон commerce_module.py для install.py
```

## Вариант А — автоматически (загрузчик модулей как в исходном проекте)

1. Скопируйте папку `commerce_realty` куда угодно (например, на флешку).
2. Проверьте проект руководителя — скрипт ничего не меняет:

   ```
   python commerce_realty/install.py "D:\путь\к\проекту" --check
   ```

   Он найдёт `app.py`, проверит загрузчик модулей, `base.html`, свободен ли адрес
   `/modules/commerce`, зависимости и базу. Строки `[ок]` — всё совпадает,
   `[!]` — есть отличие и подсказка, что делать.
3. Установите и включите:

   ```
   python commerce_realty/install.py "D:\путь\к\проекту" --activate
   ```

   Скопирует `commerce_module.py` и `commerce_realty/` в `modules/` проекта
   (старые версии модуля сохранит как `*.bak-<время>`) и добавит одну строку
   `commerce_module, active=1` в таблицу `modules`. Если базы ещё нет —
   запустите проект один раз и повторите с `--activate`, либо включите модуль
   кнопкой в «Модули → Управление модулями».
4. Перезапустите проект → «Модули → Коммерческая недвижимость».
5. Откройте «Данные и параметры модели» → «Загрузить данные из Overpass».

## Вариант Б — вручную (если загрузчик в проекте другой или его нет)

Скопируйте папку `commerce_realty` в проект и добавьте в `app.py` после
создания `app`:

```python
from modules.commerce_realty import register as register_commerce
register_commerce(app)
```

(или `from commerce_realty import ...`, если папка лежит рядом с `app.py`).
Повторный вызов безопасен. Для совместимости с разными загрузчиками пакет
также отвечает на имена `init_app(app)` и `setup(app)`.

## Вариант В — отдельно от проекта

Если подключить не получилось, модуль работает сам по себе со своей базой:

```
python commerce_realty/standalone.py            # http://127.0.0.1:5001/
python commerce_realty/standalone.py --port 5050
```

## Настройка

Через `app.config` до подключения модуля:

| Ключ | По умолчанию | Зачем |
|---|---|---|
| `COMMERCE_URL_PREFIX` | `/modules/commerce` | если адрес занят |
| `COMMERCE_DB_PATH` | `commerce_realty/data/commerce.db` | хранить базу в другом месте |

При смене адреса поправьте `MENU['url']` в `modules/commerce_module.py`.

Регион, серверы Overpass, базовые ставки и долю расходов меняют на странице модуля.

## Реальные объявления и калибровка

Раздел «Реальные объявления и калибровка ставок» на странице модуля. Объявления
привязываются к домам OSM по адресу. Модель вычисляет, какую базовую ставку подразумевает
каждое объявление в своей точке, и по медиане в группе категорий предлагает новые ставки.
Применяются они только кнопкой «Применить калибровку», а «Вернуть исходные ставки» откатывает.

- `seed/listings_yoshkar-ola_2026-10.csv` — 64 объявления по Йошкар-Оле (Акула, Этажи, октябрь 2026),
  загружаются кнопкой «Загрузить собранные объявления».
- Свои объявления — CSV (разделитель `;` или `,`, кодировка UTF-8 или Windows-1251); пример
  скачивается кнопкой «Шаблон CSV»:

| Столбец | Что писать |
|---|---|
| `deal` | `sale` / `rent` (или `продажа` / `аренда`) |
| `category` | `retail`, `food`, `office`, `service`, `hotel`, `auto`, `warehouse`, `industrial` |
| `type` | как в объявлении, необязательно |
| `address` | `ул. Луначарского, 52` — улица и дом через запятую |
| `city` | населённый пункт; пусто — столица региона |
| `area_m2` | площадь, м² |
| `price_rub` | продажа — вся цена; аренда — плата в месяц |
| `source`, `url`, `date` | откуда взято, необязательно |

Адреса домов для привязки сохраняются при «Загрузить данные из Overpass» — объявления,
добавленные раньше, попадут на карту после загрузки.

## Перенос уже загруженных данных

Установщик данные не копирует. Чтобы не загружать заново, скопируйте файл
`commerce_realty/data/commerce.db` в ту же папку в проекте руководителя.

## Удаление

Удалите `modules/commerce_module.py` и папку `modules/commerce_realty/`,
по желанию — строку `commerce_module` из таблицы `modules`. Больше модуль
ничего в проекте не оставляет.

## Ограничения

- Leaflet подключается с unpkg.com, подложка карты — с tile.openstreetmap.org:
  без интернета карта не отрисуется (как и основная карта проекта).
- Загрузчик модулей исходного проекта подключает модули только при старте —
  после установки или включения нужен перезапуск.
